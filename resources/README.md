# Resources

Folder ini digunakan untuk indeks referensi umum yang mendukung proses belajar.

## Aturan
- Utamakan tautan ke sumber resmi atau materi yang memang boleh dibagikan.
- Cantumkan judul, penulis/organisasi, tahun, dan tanggal akses bila relevan.
- Jangan mengunggah ulang buku, slide, atau materi berhak cipta tanpa izin.
- Pisahkan referensi umum dari jawaban tugas agar sumbernya jelas.
