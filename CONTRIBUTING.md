# Panduan Menambahkan Tugas

Agar arsip mudah dibaca dan dirawat, ikuti aturan berikut.

## 1. Penamaan folder

Gunakan huruf kecil, angka, dan tanda hubung.

Contoh:
- `praktikum-01-pengenalan-python`
- `tugas-02-query-sql`
- `laporan-glcm-klasifikasi-citra`

Hindari nama seperti `New Folder`, `fix-final-baru`, atau `tugas paling final`.

## 2. Isi folder tugas

Jika relevan, sertakan:
- `README.md` berisi tujuan, kebutuhan, cara menjalankan, dan hasil.
- Source code.
- `requirements.txt` atau daftar dependensi.
- Data contoh berukuran kecil yang boleh dibagikan.
- Screenshot hasil jika memang membantu.

## 3. Commit yang jelas

Contoh pesan commit:
- `docs: tambah ringkasan praktikum basis data`
- `feat: tambahkan implementasi histogram citra`
- `fix: perbaiki instruksi menjalankan program`

## 4. Keamanan dan privasi

Jangan commit `.env`, password, token, API key, data pribadi, atau dataset yang tidak memiliki izin untuk dibagikan.
