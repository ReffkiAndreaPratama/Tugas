# Kewirausahaan

## Deskripsi
Tempat mengarsipkan tugas perencanaan usaha, analisis biaya, pemasaran, dan laporan kegiatan kewirausahaan.

## Format arsip yang disarankan
- Latar belakang dan ide usaha
- Target pasar
- Rencana produk dan pemasaran
- Perhitungan modal, biaya, harga, dan pendapatan
- Evaluasi serta pembelajaran
