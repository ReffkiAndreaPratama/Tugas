# Computer Vision

## Deskripsi
Tempat mengarsipkan tugas dan praktikum pengolahan serta analisis citra digital.

## Topik yang relevan
- Representasi dan prapemrosesan citra
- Histogram dan operasi dasar citra
- Ekstraksi fitur tekstur, termasuk GLCM
- Ekstraksi fitur bentuk
- Pelatihan, evaluasi, dan analisis kesalahan model klasifikasi

## Panduan
Saat menambahkan implementasi, dokumentasikan sumber dataset, pembagian data, fitur yang digunakan, metrik evaluasi, dan cara menjalankan program. Jangan mengklaim hasil akurasi sebelum pengujian benar-benar dilakukan.
