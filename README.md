> Repository ini digunakan sebagai arsip akademik pribadi untuk menyimpan dan mendokumentasikan proses belajar di Program Studi Informatika, Fakultas Teknik, Universitas Bengkulu.

## 🎯 Tujuan

- Menyimpan tugas dan praktikum secara terstruktur.
- Mendokumentasikan materi, metode penyelesaian, dan hasil pembelajaran.
- Memudahkan pencarian kembali tugas berdasarkan semester dan mata kuliah.
- Menjadi catatan perkembangan kemampuan selama kuliah.

## 🧭 Format Pengarsipan

Setiap mata kuliah sebaiknya memiliki:
- `README.md` — ringkasan mata kuliah dan daftar tugas.
- Folder tugas atau praktikum — kode, laporan, dataset kecil, atau bahan presentasi.
- `assets/` — gambar pendukung jika diperlukan.
- `requirements.txt` atau petunjuk instalasi — jika tugas membutuhkan dependensi.

Gunakan nama folder yang singkat dan konsisten, misalnya `praktikum-01-dasar-python` atau `laporan-glcm-klasifikasi-citra`.

## 🛠️ Teknologi

Teknologi yang digunakan mengikuti tugas masing-masing, misalnya:
- Python dan Jupyter Notebook
- HTML, CSS, JavaScript
- Java
- SQL dan sistem basis data
- Git dan GitHub

Daftar ini merupakan teknologi yang dapat digunakan dalam arsip, bukan pernyataan bahwa setiap teknologi sudah dipakai pada seluruh tugas.

## 🚀 Cara Menggunakan

1. Buka folder semester yang sesuai.
2. Pilih folder mata kuliah.
3. Baca README di dalam folder sebelum menjalankan tugas.
4. Ikuti instruksi instalasi dan eksekusi yang dicantumkan pada tugas.

## 📌 Catatan

- Materi tugas akan ditambahkan secara bertahap berdasarkan berkas yang benar-benar tersedia.
- Informasi yang belum terverifikasi tidak ditandai sebagai tugas selesai.
- Perhatikan etika akademik dan hak cipta saat membagikan materi perkuliahan.
- Jangan unggah kata sandi, token, API key, data pribadi, atau file konfigurasi rahasia.
